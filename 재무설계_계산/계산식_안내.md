# 상담용 재무 계산 정의

투자 시뮬레이터는 변경하지 않았습니다. 본 모듈은 재무상태·목표자금·은퇴 현금흐름을 계산합니다. TypeScript 원본은 재무계산.ts, 실행 코드는 `npm run 계산:빌드`로 생성합니다.

- 금액: 원. 사용자 ‘300만원’은 3,000,000원으로 정규화하며 입력 원문을 보존합니다.
- 기간: 정수 개월, 나이는 정수 세. 생일·연금 지급월 단위의 정밀 연령 계산은 미구현입니다.
- 연율: 5는 5%. 월 실효율 `r = (1 + 연율/100)^(1/12) − 1`. **기존 투자 시뮬레이터의 연율/12 방식과 구분**합니다.
- 납입/생활비/연금은 월말, 최종 금액 원 단위 반올림. 연금 개시나이 포함·종료나이 미포함입니다.
- 세금·수수료·시장 변동 확률은 미반영합니다. 결과는 입력 가정에 따른 계산이지 전망이 아닙니다.

## 기본 재무상태

총자산 = 자산 목록 합, 총부채 = 부채 목록 합, 순자산 = 총자산 − 총부채.
월 지출 = 생활비 + 대출상환액 + 연 비정기지출/12. 월 잉여현금흐름 = 실수령액 − 월 지출.
저축 후 여유금 = 잉여현금흐름 − 월 저축액. 저축률 = 명시된 저축액/실수령액×100.
부채비율 = 총부채/총자산×100 (DSR·DTI 아님). 비상자금 개월 수 = 비상자금/월 필수지출.

분모가 0이거나 항목이 없으면 null. 누락 항목을 0으로 채우지 않습니다. 부채비율과 저축률의 ‘적정 기준’은 코드에 임의로 넣지 않습니다. 챗봇은 부분 자산 목록을 총자산으로 간주하지 않고 명시된 총액을 사용합니다.

## 목표자금

`PV = FV/(1+r)^n`, `FV = PV×(1+r)^n`.

월말 필요 저축액 = `max(0, (목표금액 − 현재자금×(1+r)^n) / (((1+r)^n−1)/r))`.
영금리이면 분모는 n. 남은 기간 0개월에 목표 미달이면 오류. 이미 목표 충족이면 0.
물가 반영 미래 필요금액은 FV 식에 수익률 대신 명시된 물가상승률을 적용합니다.

## 은퇴자금

은퇴 전 현재자산은 매월 명시된 수익률로 증가하고 월말 적립액을 더합니다.
월생활비는 현재 구매력에서 은퇴 시점과 은퇴 후 각 월까지 물가를 반영합니다.
연금은 **사용자가 제공한 개시 시점 명목 예상 월액**에서 개시 후 증가율을 적용합니다. 법정 연금액을 가입이력 없이 계산하지 않습니다.
은퇴 후 월 부족액 = 월생활비 − 해당 월 지급 연금 합 − 기타 월소득.

은퇴 시점 필요자금은 마지막 월부터 `필요잔액 = max(0, (다음월 필요잔액 + 이번월 부족액)/(1+은퇴후 월수익률))`로 역산합니다. 은퇴자금 부족액 = max(0, 필요자금 − 은퇴 시점 예상자산). 초과 연금은 이후 부족에 활용하되 필요자금은 음수가 되지 않습니다.

여러 수익률·물가 가정을 각각 계산하며 그 값을 자동으로 선택하거나 전망치라고 부르지 않습니다. 연금의 법정 세금·조기/연기 조정, 배우자·유족 급여, 의료·요양 위험은 구현되지 않았습니다.
