# RAG 연결 결과 (2026-11-08)

## 활성화 범위
- 국민연금: 공식 페이지 및 제공 PDF와 대조한 기본 수급요건·지급연령·연기제도 요약.
- 디딤돌: 공식 페이지의 상환방식·신청경로 요약. 업무처리기준 전체 등록 아님.
- 2025년 귀속 연말정산: 사용자가 제공한 국세청 안내 PDF(417쪽)를 색인. 해당 귀속연도 과거 질문에만 사용.
- 연금소득: 2026-07-01 시행 소득세법 제20조의3의 범위만 제한 요약. 과세액·세율·수령전략을 계산하지 않음.
- 건강보험: 2026년도 공표 보험료율과 공식 안내식을 색인. 개인별 투자소득 보험료 계산 근거로 사용하지 않음.
- 금융소비자보호법: 제1조·제17조의 제한된 상담 참고. 시행령 및 AskYES 서비스의 법적 성격에 대한 해석은 포함하지 않음.
- 미등록: 국세청 페이지에서 별도 제공하는 2026년 개정세법 요약, 2026년 귀속 연말정산 안내, 소득세법·시행령 전체의 연금 과세 및 금융소득종합과세 세부 조문.

자료는 재무설계_자료 하위 영역에 원문 PDF 또는 공식 원문 대조 요약 Markdown과 메타데이터로 저장했다. 발행일이 미표시인 경우 null과 사유를 사용했으며 날짜를 추측하지 않았다. 개인 소득·계좌·보험 자료는 공용 RAG에 포함하지 않았다.

## 검색 기간
2025년 연말정산 PDF는 2025 귀속연도 질문에서만 검색되도록 2025-01-01~2025-12-31을 적용했다. 2026년 보험료율은 2026-01-01~검수일, 소득세법 제20조의3은 2026-07-01~검수일, 금융소비자보호법 요약은 2026-01-02~검수일로 제한했다. 이 검색 허용 기간은 법적 효력 전체를 보증하지 않는다. 자동 갱신은 없다.

## 검색·답변 동작
- 일상 표현에서 공식 표현으로 검색어를 확장한다. 예: “연금을 미리 받기” → “조기노령연금”, “매달 똑같이 갚기” → “원리금균등분할상환”. 확장어는 검색어일 뿐 금융 사실의 근거가 아니다.
- 제목·자료 영역·적용 범위·본문을 나눠 점수화하고, Markdown 제목과 문서 구간을 우선 보존하며 PDF 페이지 안은 약 650자 단위로 나눈다.
- `reviewed:true`이고 검색 기준일이 메타데이터 범위에 들어오는 자료만 검색한다. 문서 본문에서 질문 또는 확장어가 실제로 일치해야 반환한다.
- 자료가 없을 때도 일반 원칙과 선택지를 먼저 설명하고, 최신 세율·자격·개인별 금액처럼 검증이 필요한 부분만 미확인으로 표시하도록 시스템 프롬프트와 도구 안내를 보완했다.

## 검증
PDF.js 텍스트 추출에서 417쪽 모두 텍스트가 확인됐다. `npm run rag:index` 성공: 공식자료 7개, 검색 조각 887개, 경고 없음. 직접 검색 확인: “연금을 미리 받으면”은 조기노령연금 자료를 찾음, “대출 매달 똑같이 갚기”는 디딤돌 상환방식 자료를 찾음, 자료가 없는 “연금 깰 때 세금”과 2026년 귀속 연말정산은 문서 없음으로 반환, 2025년 귀속 연말정산은 과거 기준일에서 검색됨. 실제 Claude API 생성 응답 및 브라우저 화면은 확인하지 않았다.
